# KeyCraft MIDI support

Public bug reports and support for **KeyCraft MIDI**, the Blender add-on for building labeled piano and synth keyboards and animating them with a MIDI controller.

[Blender Extensions submission](https://extensions.blender.org/approval-queue/keycraft-midi/)

## Report a bug

Open the **Issues** tab, check for an existing report, then choose **New issue**. Include:

- KeyCraft and Blender versions, plus your Windows version.
- Steps to reproduce the problem, expected result, and actual result.
- MIDI controller model if the problem concerns live input.
- A small example or screenshot if helpful. Remove personal information before posting.

You can also use Issues for questions and feature requests. This tracker is public; do not post passwords, access tokens, or private files.

## Quick checks

Enable only one KeyCraft installation (Extensions or legacy Add-ons). Keep the Timeline stopped while using live MIDI. Finish recording before playing back the Timeline. KeyCraft animates geometry and does not generate sound.
